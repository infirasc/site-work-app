# 부동산 개발 보고서 자동화 — 기획서

작성일: 2026-07-22
근거 문서: [real-estate-report-automation-flow.md](real-estate-report-automation-flow.md)

## 목표
해당 부동산(주소지) 자료를 입력받아 Cap Rate, 용적률, 건폐율, 개발이익 등 핵심 지표를 자동 계산하고, 웹 리포트와 PDF 보고서 형태로 만들어주는 앱이다.

**핵심 지표 계산 공식**
- NOI = (총 월임대료 × 12) + (총 보증금 × 전월세 환산율)
- Cap Rate = NOI ÷ 매입가능예상가격 × 100
- 용적률 = 연면적 ÷ 대지면적 × 100
- 건폐율 = 건축면적 ÷ 대지면적 × 100
- 개발비용 = 연면적 × 평당 건축비
- 개발 후 가치 = (매입가능예상가격 + 개발비용) × (1 + 주변 신축 건물 ROI)
- 개발이익 = 개발 후 가치 − 매입가능예상가격 − 개발비용

## 입력
App이 받는 것 — 해당 주소지 자료 (직접 입력 + 일부 자동조회):

| 항목 | 타입 | 단위/형식 |
|---|---|---|
| 주변 실거래 및 감정평가 시세 | 숫자 | 억원 |
| 매물 시세 | 숫자 | 억원 |
| 공시지가 시세 대비 가격 | 숫자 | 억원 |
| 연면적 | 숫자 | m² |
| 건축면적 | 숫자 | m² |
| 대지면적 | 숫자 | m² |
| 건물 연식 | 숫자 | 연도(준공연도) |
| 총 임대인 수 | 숫자 | 명 |
| 총 보증금 | 숫자 | 억원 |
| 총 월임대료 | 숫자 | 억원 |
| 총 관리비 내역 | 숫자 | 억원 |
| 유동인구 | 숫자 | 명 |
| 엘리베이터 유무 | 불리언 | 있음 / 없음 |
| 주차장 | 숫자 | 면 (대) |
| 매입가능예상가격 | 숫자 | 억원 |
| 주변 신축(10년 이내) 건물 ROI | 숫자 | % *(수동 입력, 계산에만 사용 — 리포트에는 표시 안 함)* |

- 금액(억원) 항목은 **소수점 둘째 자리까지 반올림**하여 표기
- **필수 (계산에 쓰임, 비면 정지)**: 연면적, 건축면적, 대지면적, 총 보증금, 총 월임대료, 매입가능예상가격, 주변 신축 건물 ROI
- **참고용 (계산에 안 쓰임, 비어도 진행)**: 위 표의 나머지 항목 (주변 실거래 및 감정평가 시세, 매물 시세, 공시지가 시세 대비 가격, 건물 연식, 총 임대인 수, 총 관리비 내역, 유동인구, 엘리베이터 유무, 주차장)

## 단계
1. 필수 입력 항목 누락 체크 — 계산에 쓰이는 7개 항목만 대상, 나머지 참고용 항목은 비어도 진행
2. 외부 데이터 자동조회 (전월세 환산율 + 평당 건축비)
3. 수익성 지표 계산 (NOI → Cap Rate) *(검증 없이 계산만 진행)*
4. 개발 규모 지표 계산 (용적률, 건폐율) *(검증 없이 계산만 진행)*
5. 개발 사업성 계산 (개발비용 → 개발후가치((매입가능예상가격+개발비용)×(1+주변 신축 ROI)) → 개발이익) *(검증 없이 계산만 진행)*
6. 리포트 템플릿에 값 매핑 *(여기서 한 번에 검증 — 값이 비어있거나 계산이 실패했으면 정지)*
7. 웹 화면에 리포트 렌더링 — 기본 출력, 여기까지 자동 진행
8. PDF 파일로 변환 — 자동 진행 아님, 리포트 화면 상단 우측 "PDF 다운로드" 버튼 클릭 시에만 실행

## 출력
- **기본**: 웹 화면에 리포트 표시
- **선택**: 리포트 화면 상단 우측 버튼 클릭 시 PDF 다운로드
- 결과는 저장하지 않음 (세션 내에서만 유지, MVP 기준)

### 리포트 목차 (추천안)
사용자 요청에 따라 직접 구성한 추천안입니다. 순서·묶음은 조정 가능합니다.

1. **표지** — 주소지, 작성일
2. **핵심 지표 요약** — Cap Rate, 용적률, 건폐율, 개발이익을 숫자로만 한눈에 (판단·의견 문구 없음)
3. **부동산 개요** — 연면적, 건축면적, 대지면적, 건물 연식, 용적률, 건폐율
4. **시세 정보** — 주변 실거래 및 감정평가 시세, 매물 시세, 공시지가 대비 가격, 매입가능예상가격
5. **임차 현황** — 총 임대인 수, 총 보증금, 총 월임대료, 총 관리비 내역
6. **입지 특성** — 유동인구, 엘리베이터 유무, 주차 가능 면수
7. **수익성 분석** — NOI, Cap Rate
8. **개발 사업성 분석** — 개발비용, 개발 후 가치, 개발이익
9. **최종의견** — 개발이익이 음수(사업성 없음)라도 그대로 보여주고, 그 아래에 왜 그런 결론인지 짧은 이유를 나열하는 요약 의견을 덧붙임. 형식: `최종의견 - 이유1, 이유2, 이유3` (긴 서술형 코멘트가 아니라 이유를 나열하는 간단한 요약)

자유 서술형 투자의견·리스크 코멘트는 포함하지 않았습니다 — [제약](#제약) 원칙과 마찬가지로, 그 부분은 이 리포트를 보는 사람(사람)이 채우는 영역이기 때문입니다. 다만 위 9번(최종의견)에 한해서는 짧은 이유 나열 형태로 판단을 함께 보여줍니다 — 개발이익이 음수인 경우를 포함해, 이 판단이 무엇이 우수한 자산인지 아닌지를 가늠하는 데 중요한 참고 정보가 되기 때문입니다.

## 제약
**필수 항목**(위 [입력](#입력) 참고)에 빈 값, 엉뚱한 값, 비현실적인 수치가 하나라도 있으면 계산을 이어가지 않는다. 문제 있는 항목을 구체적으로 안내하고, 입력·추출값을 다시 확인/수정해달라고 요청한 뒤 계산을 정지한다. 조용히 넘어가거나 잘못된 값으로 결과를 만들어내지 않는다. **참고용 항목**은 비어 있어도 계산을 멈추지 않고, 리포트에는 "정보 없음"으로 표시한다.

**안내문 예시** ("구체적으로 안내"가 실제로 어떤 형식인지 — 문제 유형별 응대값):
- 값이 비어 있을 때: `연면적_m2: 값이 비어 있음`
- 숫자가 아닌 값을 넣었을 때: `연면적_m2: 숫자가 아님`
- 음수를 넣었을 때: `연면적_m2: 음수는 입력할 수 없음`
- 나눗셈 분모가 0일 때: `대지면적_m2: 0은 허용되지 않음 (나눗셈 분모)`
- 계산이 불가능한 값(NaN·무한대)일 때: `연면적_m2: 계산불가한 값(NaN/무한대)`

### 이상치 판단 기준 (확정)
- **1차 기준**: 음수(개발이익 제외)·0(나눗셈 분모)·미입력·계산불가(NaN, 무한대) 등 **명백한 오류만** 이상치로 판단해 정지. Cap Rate·용적률·건폐율 등 항목별 상세 정상 범위는 지금 정하지 않고 추후 별도로 확정.
- **개발이익의 음수는 이상치가 아님**: "이 개발은 사업성이 없다"는 정상적인 계산 결과로 간주하고, 계산을 멈추지 않고 그대로 보여준다. 이 값(음수 여부)은 무엇이 우수한 자산인지 아닌지를 가늠하는 중요한 신호이므로, 사업성 판단 자체는 여전히 사람의 몫이되, 리포트 마지막에 짧은 최종의견(이유 나열 형태)으로 함께 제시한다 — 형식은 [리포트 목차](#출력) 9번 "최종의견" 참고.

## 완료 기준
아래 조건을 눈으로 확인할 수 있으면 App이 잘 동작한 것으로 본다.

- 핵심 지표 요약(리포트 목차 2번)에 Cap Rate, 용적률, 건폐율, 개발이익 네 값이 빠짐없이 표시된다.
- 필수 입력칸을 비운 채 진행하면, 어떤 항목이 비었는지 구체적으로 안내하는 문구가 뜨고 계산이 멈춘다.
- "PDF 다운로드" 버튼을 클릭하면 웹 화면 리포트와 동일한 내용의 PDF 파일이 내려받아진다.
