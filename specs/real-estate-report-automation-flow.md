# 부동산 보고서 자동화 — 입력 → 처리 → 출력 흐름도

작성일: 2026-07-22

## 한눈에 보는 흐름 (8단계 요약)

```
[입력] 해당 주소지 자료
   │
   ▼
1. 필수 입력 항목 누락 체크
   │
   ▼
2. 외부 데이터 자동조회 (전월세 환산율 + 평당 건축비)
   │
   ▼
3. 수익성 지표 계산 (NOI → Cap Rate)
   │
   ▼
4. 개발 규모 지표 계산 (용적률, 건폐율)
   │
   ▼
5. 개발 사업성 계산 (개발비용 → 개발후가치((매입가능예상가격+개발비용)×(1+주변 신축 ROI)) → 개발이익)
   │
   ▼
6. 리포트 템플릿에 값 매핑  (2~5단계는 검증 없이 순차 계산 → 이 단계에서 한 번에 검증)
   ├─ 매핑 전 검증: 입력값·계산값이 모두 채워져 있는가?
   │     ├─ 비어있음 / 실패 ──▶ [중단] 무엇이 문제인지(어떤 항목이 비었는지, 어떤 계산이 실패했는지) 화면에 표시하고 프로세스 정지 — 조용히 넘어가지 않음
   │     └─ 정상 ──▶ 값 매핑 진행
   ▼
7. 웹 화면에 리포트 렌더링  ← [출력 기본값] 여기까지가 자동 진행
   │
   ▼ (사용자가 리포트 화면 상단 우측 "PDF 다운로드" 버튼 클릭 시에만 실행)
8. PDF 파일로 변환
   │
   ▼
[출력] 웹 리포트 화면(기본) + PDF 다운로드(버튼 클릭 시)
```

---

## 입력 — App이 받는 것 (해당 주소지 자료)

- 주변 실거래 및 감정평가 시세
- 매물 시세
- 공시지가 시세 대비 가격
- 연면적
- 건축면적
- 대지면적
- 건물 연식
- 임차 현황: 총 임대인 수, 총 보증금, 총 월임대료, 총 관리비 내역
- 유동인구
- 엘리베이터 유무
- 주차장
- 매입가능예상가격
- 주변 신축(10년 이내) 건물 ROI *(MVP 기준 수동 입력, 계산에만 사용 — 리포트 화면에는 표시하지 않음)*

### 필수 여부
- **필수 (계산에 쓰임, 비면 정지)**: 연면적, 건축면적, 대지면적, 총 보증금, 총 월임대료, 매입가능예상가격, 주변 신축 건물 ROI
- **참고용 (계산에 안 쓰임, 비어도 진행)**: 주변 실거래 및 감정평가 시세, 매물 시세, 공시지가 시세 대비 가격, 건물 연식, 총 임대인 수, 총 관리비 내역, 유동인구, 엘리베이터 유무, 주차장

## 처리 — 8단계 요약

| 단계 | 하는 일 | 안에 묶인 세부 계산 |
|---|---|---|
| 1 | 필수 입력 항목 누락 체크 | 계산에 쓰이는 7개 항목만 대상 (연면적, 건축면적, 대지면적, 총보증금, 총월임대료, 매입가능예상가격, 주변 신축 ROI) — 그 외 항목은 참고용, 비어도 진행 |
| 2 | 외부 데이터 자동조회 | 전월세 환산율, 평당 건축비 |
| 3 | 수익성 지표 계산 | NOI(월임대료×12 + 보증금×환산율, 관리비 제외) → Cap Rate(NOI÷매입가능예상가격) |
| 4 | 개발 규모 지표 계산 | 용적률(연면적÷대지면적×100), 건폐율(건축면적÷대지면적×100) |
| 5 | 개발 사업성 계산 | 개발비용(연면적×평당건축비) → 개발후가치((매입가능예상가격+개발비용)×(1+주변 신축 ROI)) → 개발이익(개발후가치−매입가능예상가격−개발비용) |
| 6 | 리포트 템플릿에 값 매핑 | 입력값 + 3~5단계 계산값을 정해진 서식에 배치. **매핑 전 검증**: 값이 비어있거나 계산이 실패했으면 어떤 항목인지 명시해 화면에 표시하고 즉시 정지 (조용히 넘어가지 않음) |
| 7 | 웹 화면에 리포트 렌더링 | 기본 출력. 여기까지 자동 진행 |
| 8 | PDF 파일로 변환 | 자동 진행 아님 — 리포트 화면 상단 우측 "PDF 다운로드" 버튼 클릭 시에만 실행 |

## 출력 — 최종 결과물의 형태

- **기본**: 웹 화면에 리포트 표시 (미리보기)
- **선택**: 웹 리포트 상단 우측 버튼 클릭 시 PDF로 다운로드
- 결과는 저장하지 않음 — 세션 내에서만 유지 (MVP 기준, 저장/이력 조회는 이후 단계 과제)

---

## 상세 13단계 버전 (구현 참고용)

계산 로직을 코드로 옮길 때는 아래처럼 한 단계에 한 계산만 있는 버전이 더 다루기 쉽습니다. 위 8단계는 이 13단계를 논리적으로 묶은 것입니다.

| 단계 | 하는 일 | 비고 |
|---|---|---|
| 1 | 필수 입력 항목 누락 체크 | 계산에 쓰이는 7개 항목(연면적, 건축면적, 대지면적, 총보증금, 총월임대료, 매입가능예상가격, 주변 신축 ROI)만 대상. 빠진 항목 있으면 다음 단계로 넘어가지 않음. 나머지 참고용 항목은 비어도 진행 |
| 2 | 지역 전월세 환산율 자동조회 | 외부 데이터 연동 |
| 3 | 최근 평당 건축비 자동조회 | 외부 데이터 연동 |
| 4 | NOI 산출 | 총 월임대료×12 + 총보증금×환산율 (관리비 제외) |
| 5 | Cap Rate 산출 | NOI ÷ 매입가능예상가격 |
| 6 | 용적률 산출 | 연면적 ÷ 대지면적 × 100 |
| 7 | 건폐율 산출 | 건축면적 ÷ 대지면적 × 100 |
| 8 | 개발비용 산출 | 연면적 × 평당 건축비(자동조회 값) |
| 9 | 개발 후 가치 산출 | (매입가능예상가격 + 개발비용) × (1 + 주변 신축 건물 ROI(수동입력)) |
| 10 | 개발이익 산출 | 개발후가치 − 매입가능예상가격 − 개발비용 |
| 11 | 리포트 템플릿에 값 매핑 | 입력값 + 4~10단계 계산값을 정해진 서식에 배치. **매핑 전 검증**: 값이 비어있거나 계산이 실패했으면 어떤 항목인지 명시해 화면에 표시하고 즉시 정지 (조용히 넘어가지 않음) |
| 12 | 웹 화면에 리포트 렌더링 | 기본 출력. 여기까지 자동 진행 |
| 13 | PDF 파일로 변환 | 자동 진행 아님 — 리포트 화면 상단 우측 "PDF 다운로드" 버튼 클릭 시에만 실행 |
